I contribute to experiment control software for the Liu Lab, a visual neuroscience lab. The work involves maintaining and extending a MATLAB codebase that runs behavioral experiments on mice, built around Psychtoolbox for real-time visual stimulus presentation and a finite state machine that handles trial sequencing, data logging, and hardware communication.
