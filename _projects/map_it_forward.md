Map It Forward is a participatory mapping tool for NYC residents to pin community improvement requests directly on a map. You click a location, fill out a short form describing the issue (roads, parks, schools, housing, etc.), rate the severity, and attach a photo. All submissions show up as markers on a shared Folium map so anyone can see what problems have been flagged in their neighborhood.

Built with Streamlit, with Folium for the interactive map and Geopy for reverse-geocoding coordinates into readable addresses. The map is restricted to NYC bounds. Location can be set by clicking on the map or detected automatically from the browser.
